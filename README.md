## Fitur yang Diselesaikan
1. **Komponen Reusable**: Mengembangkan komponen `DiaryCard` untuk menampilkan detail entri diary secara konsisten.
2. **Refactoring UI**: Memperbarui halaman `DiaryListScreen` agar menggunakan `DiaryCard`.
3. **Ekspansi Data**: Menambahkan daftar entri buku harian hingga 5 entri lengkap dengan gambar indikator mood.
4. **Header Profile**: Menambahkan avatar dan sapaan profil pengakses di bagian atas aplikasi.
5. **Dukungan Web**: Mengonfigurasi `react-native-web` untuk pengujian aplikasi melalui browser.
6. **Version Control**: Mengintegrasikan proyek dengan Git dan mengunggah kode ke GitHub (`revadn-lgtm/diary-app`).
